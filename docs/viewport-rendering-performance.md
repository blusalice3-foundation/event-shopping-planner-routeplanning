# 画面外のカード生成と集中モードの描画高速化

PCの一覧、スマートフォン配置のスペース別・ホール別一覧では、32行以上で画面外の操作部品の生成を遅らせる。画面と前後500pxの範囲、検索・ナビゲーターによる移動先、Tabキーの移動先で生成する。既存の行モデル、選択・フォーカス・スクロールの共通コントローラー、グループ順序と購入・編集・ドラッグのハンドラーを使用する。

全件のアクセシビリティ情報と移動先の目印を通常の文書フローに残す。生成後のカードを保持し、入力値・フォーカス・備考の展開状態を維持する。件数の閾値を越える追加・削除でも同じ部品を保持する。印刷前にはグループ内の全カードも生成する。未生成行の高さは仮の値で、生成時に内容の自然な高さになる。

スマートフォンの既存の単列仮想リストは従来の方式を使用する。今回の方式は通常の文書フローを使う独立した適用条件を持ち、IntersectionObserver・ResizeObserver、既知の100%ズーム、安定した行キー、復旧中でないことを必要とする。不明な条件・未対応ズーム・復旧中・壊れた設定・全件表示設定・QAの全件表示指定では一括描画する。

集中モードでは品目の並べ替えとマップの参照計算を共有する。数量・金額などの変更時にも最新の品目値を取り出し、配置・優先度・実行列順序・ホール・マップが変われば再計算する。同じ訪問先に80件以上ある場合は画面外の操作部品を遅れて生成し、生成後は保持する。

マップ表示時は行索引で画面内のセルを選び、結合セルの起点・元の描画順・重複セルを維持する。セル背景・文字・罫線の描画画像を再利用し、ルート・現在地・一時移動の目印を重ねる。マップ、表示範囲、回転、ズーム、テーマ、表示設定、購入状態・色などが変われば作り直す。非表示中は表示用の索引とCanvasを生成せず、経路や確認に必要な計算を継続する。

画像は1画面分、最大約16MiB。索引は最近表示したマップの合計10万セルまでを保持するが、現在の索引1個が10万セルを超える場合はその1個を保持する。上限を超えた過去の索引は解放し、必要な時に作り直す。生成済みの品目DOMは画面外でも保持するため、全行を閲覧した後のDOM使用量は全件描画に近づく。

状態更新、変更計画、確認、保存キュー、整合性・競合・破損の検証、保存確定は既存の共通経路のままで、前回の保存高速化も維持する。

## 動作の検証

行の順序・ARIA情報、画面外のネイティブ操作部品の生成、入力とフォーカス、閾値を越える追加・削除、ドラッグ移動、ナビゲーターの移動先、印刷前の全件生成、前後のTab移動、監視解除、設定・ズーム・復旧時の一括描画を検証する。

マップは疎な行、結合セルの起点、重複セルの描画順、スペースの正規化、重複したブロックの曖昧性、参照計算の一致、索引の破棄・再生成、描画内容の変更時の更新、描画できない場合の通常処理を検証する。

実ブラウザーで240件の画面外移動・金額と数量の独立した変更・IndexedDBへの保存・参加日の往復、1スペース240件、集中モードの購入・数量変更とマップ表示の切替を確認する。別途、1万セル・75件に結合セル、縦書き、文字色、背景色、太線・二重罫線を含め、安定したCanvasのPNGのSHA-256を比較した。初期表示・数量変更・購入変更・再表示・次の訪問先の5状態が変更前後ですべて一致した。この条件の画像確認であり、全マップの網羅的な画像比較ではない。

既存の購入状態・確認・保存失敗・再試行・復旧の検証と、品質・ブラウザー・ロールバックの検証を維持する。

AGENTS.mdのUTF-8コンソールラッパーを適用し、比較するソースごとにnpm run build:appを実行する。ビルドを異なるポートで配信し、計測は順番に実行する。

```powershell
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 4175 --strictPort
```

```powershell
$taskSamples = Get-Content -LiteralPath docs/viewport-rendering-performance.samples.json -Raw -Encoding utf8 | ConvertFrom-Json
$env:DAY_TAB_CASES = ConvertTo-Json -InputObject @($taskSamples.after | ForEach-Object { $_.case }) -Depth 12 -Compress
$env:PLAYWRIGHT_BASE_URL = 'http://127.0.0.1:4175'
node scripts/performance/dayTabLatency.mjs
```
