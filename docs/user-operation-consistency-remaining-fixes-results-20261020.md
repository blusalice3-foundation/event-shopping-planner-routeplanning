## 今回の変更

製品コードは3ファイル、回帰試験は5ファイル。保存契約・DB/バックアップ形式・依存ライブラリを変更していない。

1. [modalFocusBoundary.ts](../src/utils/modalFocusBoundary.ts): 登録順だけでなく、祖先を含む表示階層と同階層のDOM順で最前面のfocus所有者を決める。祖先の低い階層を子の大きなz-indexが飛び越えないようにする。遅れて開いた背面modalは前面所有者の復帰先を引き継ぎ、最後のcloseでも本来の起点へ戻す。
2. [useModalDialogBehavior.ts](../src/hooks/useModalDialogBehavior.ts): 初期focusは最前面の所有者だけに設定する。確認A→B、busy、入れ子、保存失敗focusの保留と最後の復帰を維持する。
3. [MapImportDialog.tsx](../src/components/map/MapImportDialog.tsx): プレビューへの解析所有権移行時に旧取込の`isLoading`を解除する。旧解析のfinallyの所有者照合は残し、次の解析・保存待ちを旧要求が解除しないようにする。

表示階層のstyle読取はmodalを開く時の祖先経路だけで行う。通常の購入・数量・メモやdrag moveに、新しい全件走査・snapshot複製・保存I/O・全カード再描画を追加していない。
