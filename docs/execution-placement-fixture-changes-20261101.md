## 表示IDと機能試験の互換調整

異なる所属・優先度の場所からの補正案内（D05）は仮の状態であり、受付とは区別する。案内やスクロールだけで保存せず、静止したポインターの下へ有効位置が移動しても確定可能には変えない。ユーザーが有効範囲へ実際に移動してdropする必要がある。この区別により、既に同じ配置グループ内にいる操作へ、計画にない「同じ訪問そのものをhoverしなければならない」という追加制限を設けない。
