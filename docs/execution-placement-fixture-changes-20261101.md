## 負荷を保つ住所の交換

performanceFixture()だけで、既存の画面外訪問`offscreen`と最後のA所属の通常fillerの住所を交換する。150品目は`execute-69`のA-79、500品目は`execute-244`のA-254を使う。`offscreen`はそれぞれA-79a / A-254a、`merge-offscreen`は同スペースの追加本A-79a2 / A-254a2とし、交換したfillerが元のB-999aを引き継ぐ。

これにより、品目ID、全品目数150/500、実行/候補の件数、元の品目配列・実行列ID順、A/Bの両ホール、各ブロックの地図番号セルの集合・件数・寸法、価格・数量・購入状態を保持する。地図の番号解決は既存の整数部照合を使う。元のfixture()のB所属offscreenは変更しない。独立したfixture負荷確認を150/500に各1件置き、元の番号集合と地図セル、実行ID順、混在拒否用の元B所属を照合する。
